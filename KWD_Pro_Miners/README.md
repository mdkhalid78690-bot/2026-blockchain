# KawaidCoin (KWD) Multi-Core CPU Miner (v1.1.1)

Official multi-core CPU miner for KawaidCoin Mainnet (`https://kawaidcoin.xyz`).
GPU mining scripts have been deprecated for Phase 1 so all laptop and desktop CPU miners compete fairly.

## Quick Start (Windows / Linux / macOS)
- **Requirements:** `pip install requests`
- **Windows:** Double-click `start_multicore_miner.bat` and enter your KWD wallet address and CPU core count.
- **CLI:** `python kwd_fast_miner.py <YOUR_KWD_WALLET> https://kawaidcoin.xyz 4`
